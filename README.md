### Welcome to my simple 1 month stock tracker

---

To run this project make sure you have Node.js installed and then:
* Navigate to the root folder and run: ```npm install```
* After this is complete, still in the root folder run: ```npm run install:all```
* Wait for dependencies to install
* Run```npm run dev``` and ctrl + click the green link in the terminal using localhost
* Your default browser should open the stock tracker

NOTE: On port 3000 you can access the api docs using /docs
